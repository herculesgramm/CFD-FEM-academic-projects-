Nonlinear Boundary Value Problem: Picard vs Newton-Raphson

A finite element solution of a strongly nonlinear differential equation by two iterative methods, comparing how fast each converges and how much the starting guess matters.

  • Galerkin FEM
  • Picard iteration
  • Newton-Raphson
  • Quadratic elements

University of Thessaly, Mechanical Engineering. Computational Fluid Dynamics with Finite Elements course, Assignment 3

The problem

Find u(x) on [0, 1] that satisfies:

−d/dx[(u + √2) du/dx] + sin(−2u) du/dx + u eᵘ cos u = 1, with u′(0) = 0 and u(1) = −1.

The equation is nonlinear, so the finite element system cannot be solved in one step. Both methods start from a guess and improve it repeatedly.

Approach

  • Discretisation. Multiplying by a test function and integrating by parts gives element equations in the nodal values uj. The insulated end is a natural boundary condition and u(1) = −1 is imposed directly.
  • Picard. Freeze the nonlinear coefficients at the previous iterate and solve the resulting linear system [K(u)]{u} = {F} + {S}. Repeat until the change is negligible.
  • Newton-Raphson. Write the discrete equations as a residual {R} = 0, expand with a Taylor series, and solve (∂R/∂u){δu} = −{R} for each correction. This needs the full Jacobian, which I derived by hand.
  • Comparison. Relative error per iteration for several starting guesses, measured against the solution obtained from a guess of 0.04.

What I found

  • The starting guess does not change how fast either method converges. It does change which answer you get.
  • Newton-Raphson is faster but fragile: for guesses near −1 it settles on a different answer, with relative error around −60 compared to the correct solution.
  • Picard is slower but forgiving. It stays accurate over a very wide range of guesses and only diverges for very large ones.
  • The converged solution starts near u = −0.15 at x = 0 and falls to −1 at x = 1.
